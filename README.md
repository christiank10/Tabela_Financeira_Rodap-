# Tabela de Movimentações Financeiras + Rodapé

Projeto prático desenvolvido em **HTML5** e **CSS3** puro com foco em estrutura semântica, estilização moderna em tema escuro (dark mode) e layout responsivo para exibição de movimentações financeiras.

## Demonstração Online
Acesse o projeto funcionando diretamente no navegador via GitHub Pages:
[Ver Projeto Online](https://christiank10.github.io/NOME-DO-REPOSITORIO/)

## Tecnologias Utilizadas
* **HTML5:** Estrutura semântica utilizando `<main>`, `<table>`, `<thead>`, `<tbody>` e `<footer>`.
* **CSS3:** Flexbox para alinhamento estrutural (`min-height: 100vh`), `border-collapse`, efeitos de transição (`:hover`) e paleta de cores dark mode.
